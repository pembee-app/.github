# Pembee

Pembee is booking and payments software for activity providers: kids' clubs, holiday camps, sports academies, dance and martial arts schools, yoga studios and anyone else running classes or sessions.

Providers use Pembee to list their activities, take bookings and payments online, manage attendees and registers, run subscriptions and memberships, and accept Tax-Free Childcare and childcare vouchers. Parents and customers get a simple, branded booking site they can use from their phone.

🌐 [pembee.app](https://pembee.app)

## What we build

- **Booking platform**: the customer-facing booking sites and the admin dashboard providers use to run their business
- **Console**: internal tooling for the Pembee team to support and manage client accounts
- **Payments**: card payments, invoicing and subscriptions built on Stripe Connect, with each provider paid directly
- **Integrations**: Zapier, email, and the other tools providers already rely on

## Stack

Next.js · React.js · TypeScript · MongoDB · Stripe · Tailwind · Bun · Vercel
